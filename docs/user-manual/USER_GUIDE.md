# دليل المستخدم — Eltaranisi ERP
## (للمحاسب، ومدير الشركة، والمدير المالي)

---

## 1. الدخول إلى النظام

1. افتح `http://localhost:8000`.
2. اكتب **اسم المستخدم** و**كلمة المرور** (من `data/dev-credentials.txt` في بيئة التطوير).
3. لإظهار كلمة المرور اضغط أيقونة العين.
4. زر **AR / EN** أعلى الشاشة يبدّل اللغة والاتجاه (RTL ⇄ LTR) بدون إعادة تحميل.
5. زر القمر/الشمس يبدّل الوضع الليلي. النظام يتذكّر اختيارك.

> إذا ظهر «اسم المستخدم أو كلمة المرور غير صحيحة» بعد 8 محاولات، الحساب مقفول 15 دقيقة.

---

## 2. الشاشة الرئيسية (لوحة المعلومات)

- **بطاقات المؤشرات**: الإيرادات، المصروفات، صافي الربح، السيولة النقدية،
  **إجمالي مديونية الموردين**، **المتأخر منها**، مستحقات العملاء، قيمة المخزون.
- **الرسم البياني**: الإيرادات مقابل المصروفات لآخر 6 أشهر.
- **أرصدة البنوك والصناديق**.
- **أعلى الموردين مديونية** + تاريخ أقرب استحقاق.
- **أعمار الديون** (مدينة ودائنة).
- **الإجراءات السريعة**: قيد جديد · فاتورة بيع · سند قبض.

كل الأرقام من القيود المرحّلة فقط. لا مسودات، ولا أرقام تقديرية.

---

## 3. القيود اليومية (دورة القيد)

### إنشاء قيد
1. **القيود اليومية** ← «قيد جديد».
2. اختر التاريخ، النوع (يدوي/افتتاحي/تسوية/مصروف…)، واكتب البيان.
3. أضف السطور: الحساب + مدين أو دائن + الوصف.
4. الميزان أسفل النموذج يجب أن يكون **متوازنًا** (أخضر). إذا كان أحمر لا يُحفظ.
5. **حفظ كمسودة** ← يظهر رقم القيد (`JE-2026-xxxxx`).

### المراجعة والترحيل
| الحالة | من يتحرك | ماذا يفعل |
|---|---|---|
| مسودة | المُنشئ | يرسل للمراجعة زر «إرسال للمراجعة» |
| مراجعة | رئيس الحسابات / المدير المالي | يعتمد أو يرفض بسبب مكتوب |
| معتمد | صاحب صلاحية الترحيل | «ترحيل» ← القيد يُؤثر في الأرصدة |
| مرحّل | — | **لا تعديل**؛ التصحيح بقيد عكسي |

> **قاعدة مهمة**: لا يمكنك اعتماد قيد أنت منشئه (فصل مهام). يحتاج قيد ثانٍ بشري.
> القيود ≥ **200,000 ج.م** تحتاج اعتماد المدير المالي.

### عكس قيد
افتح القيد المرحّل ← «عكس القيد» ← اكتب السبب. يُنشأ قيد عكسي مرحّل بقيم متساوية، ويبقى الأصل
في السجلات للمراجعة.

### استيراد CSV
«استيراد القيود» ← اختر الملف ← يتحقق النظام من التوازن والحسابات والفترات ويُظهر الأخطاء سطرًا بسطر
قبل أي ترحيل.

## 4. الفواتير

### فاتورة بيع
1. **المبيعات** ← «فاتورة جديدة».
2. اختر العميل (يظهر رصيده وحد ائتمانه)، المستودع، التاريخ وتاريخ الاستحقاق.
3. أضف الأصناف: الكمية، السعر، الخصم، نسبة الضريبة.
4. **حفظ كمسودة** ثم **ترحيل**، أو ضع علامة «ترحيل فوري».
5. عند الترحيل يتأثر: حساب العميل (مدين)، الإيرادات (دائن)، ضريبة المبيعات (دائن)،
   المخزون وتكلفة المبيعات تلقائيًا.

### فاتورة شراء
نفس الخطوات: المورد، المستودع، الأصناف، ثم الترحيل ← يزيد المخزون ويظهر التزام على المورد.
لا تُقبل فاتورة بنفس رقم مرجع المورد مرتين.

### سند قبض / صرف
- **سند قبض**: العميل + المبلغ + الحساب البنكي/الصندوق + تخصيص المبلغ على الفواتير.
- **سند صرف**: المورد أو حساب المصروف + الحساب البنكي/الصندوق.
- لا يمكن تخصيص أكثر من رصيد الفاتورة المتبقي — يظهر خطأ `OVER_ALLOCATION` بوضوح.

---

## 5. مديونية الموردين (أهم تقرير للمدير المالي)

**المشتريات → مديونية الموردين**:
- إجمالي المديونية، المدفوع، المتبقي، المتأخر، أقرب استحقاق каждой فاتورة.
- أعمار الديون في 5 نطاقات.
- عمود **«رصيد الأستاذ»** يجب أن يطابق المتبقي — إن اختلفا فهناك مشكلة تستحق الفحص.
- تصدير CSV، أو طباعة PDF من المتصفح.

---

## 6. التقارير

كل تقرير يقبل **الفترة + الفرع + المركز**، ويُصدَّر CSV/Excel وطباعة PDF.

| التقرير | الاستخدام |
|---|---|
| ميزان المراجعة (ملخص/تفصيلي) | التحقق من توازن الحسابات |
| قائمة الدخل | الأرباح والخسائر للفترة |
| المركز المالي | الأصول = الالتزامات + حقوق الملكية |
| التدفقات النقدية | حركة البنوك والصناديق |
| أعمار الديون | متأخرات العملاء والموردين |
| الأستاذ العام | حركة حساب معين بتفصيل |
| موازنة مقابل الفعلي | الانحرافات وتجاوز الموازنة |

> إن أظهر ميزان المراجعة فرقًا غير صفري، **لا تُرحّل أي شيء**؛ أبلغ المحاسب المسؤول.

---

## 7. الشاشات التشغيلية

| الشاشة | ما تفعله |
|---|---|
| المخزون | أرصدة الأصناف، المستودعات، الحركات، إعادة طلب |
| البنوك | الأرصدة، الحركات، المطابقة البنكية (الاقتراح يحتاج تأكيدًا بشريًا) |
| الأصول الثابتة | السجل، الإهلاك الدوري، مجمع الإهلاك |
| الرواتب | الموظفون، مسير الرواتب، الصافي والاستقطاعات، القيد التلقائي |
| الموازنات | التخطيط الشهري ومقارنته بالفعلي |
| الموافقات | القيود والفواتير المنتظرة — بالعتبة والمستوى |
| الفترات المالية | إقفال شهر/سنة وإعادة فتح مع تسجيل من فعل ذلك |
| المستخدمون | الأدوار والصلاحيات (مالك الشركة فقط) |
| سجل التدقيق | كل عملية: من، ماذا، متى، من أي جهاز |

---

## 8. المساعد المالي

اسأله بلغة عادية، مثل:
- «إجمالي مديونية الموردين والمتأخر منها؟»
- «صافي ربح هذا الشهر؟»
- «كم رصيد البنك؟»

يعرض **مصدر الأرقام** ويقول صراحةً إنه من القيود المرحّلة. **لا ينفذ أي عملية**: لا يرحّل ولا يدفع
ولا يحذف، ولا يرى إلا ما تسمح به صلاحياتك. والتوقعات (إن طلبتها) تُعرض كتقديرات احتمالية.

---

## 9. حقوقك حسب دورك

| أنت | تستطيع |
|---|---|
| مالك الشركة | كل شيء داخل شركتك، بما فيه المستخدمون والإعدادات |
| المدير المالي | كل عمليات المحاسبة والتقارير والاعتماد — بلا إدارة مستخدمين |
| رئيس الحسابات | الإنشاء والمراجعة والترحيل، بلا إدارة مستخدمين |
| محاسب | إنشاء القيود والفواتير وطلب المراجعة فقط |
| مبيعات/مشتريات | الدورة التشغيلية بلا ترحيل محاسبي |
| مراجع | قراءة وتقارير فقط |

## 10. تصدير المستندات وإعدادات الشركة (جديد)

### تصدير فاتورة
افتح الفاتورة ← أعلى الصفحة زر **📄 PDF / طباعة**:
- **معاينة وطباعة** — يعرض نفس ملف PDF داخليًا مع إمكانية الطباعة.
- **تنزيل PDF عربي / إنجليزي** — نفس الفاتورة بلغة مختلفة (الخط العربي مضمَّن داخل الملف).
- **Excel** — نسخة RTL قابلة للتحرير.
- **فاتورة إلكترونية** — بيانات JSON جاهزة مع UUID وبصمة SHA-256 (غير موقّعة) وزر نسخ.

> كل تنزيل يمرّ عبر جلسة المستخدم ويُسجَّل في سجل التدقيق باسمك — لا روابط عامة قابلة للتخمين.

### تصدير تقرير
في أي تقرير (ميزان المراجعة، قائمة الدخل، المركز المالي، التدفقات، أعمار الديون، مديونية الموردين)
اضغط **⬇ تصدير** واختر: PDF عربي · PDF إنجليزي · Excel (RTL) · CSV. الفلاتر المطبّقة على الشاشة
(من/إلى تاريخ) تنتقل نفسها إلى الملف.

### إعدادات الشركة
**إعدادات الشركة** في القائمة الجانبية (لمن يملك صلاحية `settings.manage`): الاسم العربي/الإنجليزي،
الرقم الضريبي، الهاتف، العنوان، البريد، الموقع، بيانات البنك، شروط السداد، وتذييل الفاتورة — مع
**معاينة حيّة** لرأس الفاتورة. ما تكتبه هنا يُطبع فورًا على كل PDF/Excel جديد.

## 11. أسئلة متكررة

**«لماذا لا يظهر القيد في ميزان المراجعة؟»** لأنه مسودة أو قيد غير مرحّل — المرور بالمراجعة والترحيل مطلوب.

**«رسالة SOD_VIOLATION»** يحاول شخص اعتماد قيده/فاتورته بنفسه. اطلب من شخص آخر الصلاحية.

**«PERIOD_CLOSED»** الترحيل ممنوع على فترة مقفلة. راجع شاشة الفترات المالية.

**«لا أستطيع تصدير ملف»** صلاحية التصدير منفصلة عن صلاحية العرض؛ راجع مدير النظام.

**«هل الأرقام حقيقية؟»** نعم — كل بطاقة وتقرير محسوب من قاعدة البيانات. بيانات التطوير موسومة بوضوح.
